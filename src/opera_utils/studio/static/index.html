Connect to OPERA Studio

This page is the studio's interface. Searching, downloads, rebasing and your Earthdata login run in a small server on your own machine; nothing goes through this website.

  1. Install opera-utils with the studio's dependencies:
    pip install "opera-utils[studio]"
  2. Start the studio and let this page talk to it:
    opera-utils studio --allow-origin
  3. Connect below. If the browser asks to let this site access other apps and services on this device, choose Allow: that is how the page reaches the studio on your machine.

Or open the address the command prints, which needs no --allow-origin.
